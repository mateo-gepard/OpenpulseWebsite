OpenPulse Gen 2

Daten und API: jeder Messwert, kein Score

OpenPulse Gen 2 zeichnet jeden Rohwert mit Zeitstempel im Gerät auf. Über das USB-Dock kopieren Sie die Daten auf Ihren eigenen Rechner und arbeiten damit als Dateien, in Python oder über eine lokale API. Ohne Cloud und ohne Konto dazwischen. Die API ist in Entwicklung; Namen und Beispiele auf dieser Seite zeigen die geplante Schnittstelle.

Kanäle und Abtastraten

Pulslicht mit 100 Hz, Bewegung mit 50 Hz, Haut und Luft dazwischen, jeder Wert mit Zeitstempel. Als CSV, Parquet oder EDF, oder direkt in Python und Ihre eigenen Werkzeuge. Ohne Cloud dazwischen.

QuellePortKanäleRate
PulseA oder Bppg.green.pd1, ppg.green.pd2, ppg.red.pd1, ppg.red.pd2, ppg.ir.pd1, ppg.ir.pd2100 Hz · 24 bit
Bewegung (IMU)Coreacc.x, acc.y, acc.z, gyro.x, gyro.y, gyro.z50 Hz · 16 bit
Thermo+A oder Bskin.temp1, skin.temp21 Hz · 16 bit
AirEair.temp, air.humidity, air.pressure, air.gasalle 3 s · 20 bit

Kanalnamen folgen dem Muster quelle.signal.detektor: ppg.ir.pd1 ist das Infrarot-PPG von Photodiode 1. Jede Aufzeichnung trägt außerdem Typ, Seriennummer und Kalibrierung, die in jedem Puck gespeichert sind. Die Kanäle des EKG- und des EDA/BioZ-Pucks werden mit der API veröffentlicht.

Dateiformate

  • CSV: eine Zeile pro Messwert, Zeitstempel in Mikrosekunden (t_us) und eine Spalte je Kanal.
  • Parquet: eine Datei je Quelle, etwa op-2F41_pulse.parquet, op-2F41_imu.parquet.
  • EDF / BDF: für klinische und physiologische Werkzeuge und EDF-Viewer.

Schnittstellen

Python

import openpulse as op
dev = op.Device.usb()                # lokal, kein Konto, kein Upload
df = dev.raw(["ppg.green.pd1", "ppg.ir.pd1", "acc.z"],
             start="2026-11-13 22:00", end="2026-11-14 06:00")

Kommandozeile

op devices
op export op-2F41 --from 2026-11-13 --format parquet,bdf --out ./raw

Lokale HTTP-API

curl "localhost:8473/v1/devices/op-2F41/raw?channels=ppg.ir.pd1&format=csv"

MCP-Server für KI-Assistenten

Ein lokaler MCP-Server lässt einen KI-Assistenten auf Ihrem Rechner die Rohdaten lesen, etwa: „Zeig mir mein rohes IR-Signal von letzter Nacht gegen 3 Uhr und markiere die Bewegungsartefakte.“ Der Assistent ruft das Werkzeug openpulse.raw mit Kanälen und Zeitraum auf; die Daten bleiben auf Ihrem Rechner.

Daten vom Gerät holen

Das Gerät speichert die Rohdaten im eigenen Speicher (Auslegung: 2 Gbit, rund ein Tag Rohdaten bei voller Rate). Im USB-Dock lädt es und kopiert die Daten auf Ihren Rechner.
