OpenPulse Gen 2

Data and API: every sample, not a score

OpenPulse Gen 2 records every raw sample with its timestamp on the device. You copy the data to your own computer through the USB dock and work with it as files, in Python or through a local API. No cloud and no account in between. The API is in development; names and examples on this page show the planned interface.

Channels and sample rates

Pulse light at 100 Hz, motion at 50 Hz, skin and air in between, each with its timestamp. As CSV, Parquet or EDF, or straight into Python and your own tools. No cloud in between.

SourcePortChannelsRate
PulseA or Bppg.green.pd1, ppg.green.pd2, ppg.red.pd1, ppg.red.pd2, ppg.ir.pd1, ppg.ir.pd2100 Hz · 24 bit

Channel names follow source.signal.detector: ppg.ir.pd1 is the infrared PPG signal from photodiode 1. Every recording also carries the type, serial number and calibration stored in each puck. Channels for the EKG and EDA / BioZ pucks will be published with the API.

File formats

  • CSV: one row per sample, timestamp in microseconds (t_us) plus one column per channel.
  • Parquet: one file per source, for example op-2F41_pulse.parquet, op-2F41_imu.parquet.
  • EDF / BDF: for clinical and physiology tools and EDF viewers.

Interfaces

Python

import openpulse as op
dev = op.Device.usb()                # local, no account, no upload
df = dev.raw(["ppg.green.pd1", "ppg.ir.pd1", "acc.z"],
             start="2026-11-13 22:00", end="2026-11-14 06:00")

Command line

op devices
op export op-2F41 --from 2026-11-13 --format parquet,bdf --out ./raw

Local HTTP API

curl "localhost:8473/v1/devices/op-2F41/raw?channels=ppg.ir.pd1&format=csv"

MCP server for AI assistants

A local MCP server lets an AI assistant on your computer read the raw data, for example: “Show me my raw IR signal from last night around 3 am and mark the motion artefacts.” The assistant calls the tool openpulse.raw with the channels and time range; the data stays on your computer.

Getting data off the device

The device stores raw data in its onboard memory (design target: 2 Gbit, about one day of raw data at full rate). Docked over USB, it charges and copies the data to your machine.
